## Основні проєкти

### UTTER

Платформа для практики англійської мови з голосовим AI-наставником.

Можливості:

- голосове спілкування в реальному часі;
- розпізнавання мовлення;
- генерація відповідей за допомогою LLM;
- синтез мовлення;
- аналіз відповідей користувача;
- автентифікація та рольова модель доступу.

Технології: React Native, Next.js, TypeScript, Python, WebSockets, PostgreSQL, Redis, Docker.

Статус: активна розробка.

[Переглянути репозиторій](https://github.com/DmytroZyniar/UTTER-MODERN)

### Content Messenger

Месенджер із підтримкою realtime-чатів, вкладень, двофакторної автентифікації та функцій приватності.

Технології: TypeScript, Node.js, React, PostgreSQL, Prisma, Pusher.

Статус: у розробці.

[Переглянути репозиторій](https://github.com/DmytroZyniar/chat-msg)
